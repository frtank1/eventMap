# 07_Testing

## Папки

- **unit/** — юнит-тесты в `shared/commonTest` (UseCase, ViewModel)
- **ui/** — Compose UI-тесты
- **e2e/** — end-to-end сценарии (Maestro flows)
- **bug_reports/** — markdown файлы с описанием багов: один файл = один баг
