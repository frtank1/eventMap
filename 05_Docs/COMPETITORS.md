# EventMap — Конкуренты и позиционирование

> Обзор соседних ниш по состоянию на июнь 2026. Цель — честно понять, где EventMap пересекается с существующими продуктами и где у него свободный угол. Короткий вывод: компоненты идеи не уникальны (так почти всегда), но **комбинация «живая карта событий + live-видео + локальный контент»** свободна, особенно для Казахстана.

---

## 1. Карта местности: три соседние ниши

Ни один из существующих продуктов не закрывает то, что строит EventMap, целиком. Они делятся на три группы.

### A. Афиши и билеты — «что будет», без живого слоя

| Продукт | Что делает | Чего нет (vs EventMap) |
|---|---|---|
| **Eventbrite** | Публичные события + билеты, большой discovery-маркетплейс | Нет живой карты «сейчас», нет видео с места |
| **Meetup** | Сообщества и регулярные встречи по интересам (60M+) | Нет карты реального времени, фокус на группах |
| **Luma** | Современные страницы событий, tech/стартап-комьюнити | Каталог, не карта; нет «живого» слоя |
| **Partiful** | Личные/социальные ивенты, виральные инвайты | Личные тусовки, не город как карта |
| **Ticketon (KZ)** | Афиша + продажа билетов по Казахстану | Каталог, нет карты реального времени и видео |
| **Sxodim / Давай Сходим (KZ)** | «Куда сходить» в Алматы и городах КЗ | Афиша/гид, нет живого слоя и видео |

Самые прямые **локальные** соседи по контенту — Ticketon и Sxodim, но это каталоги афиш, а не живая карта.

### B. Live-карты людей — реальное время, но не события

| Продукт | Что делает | Чего нет (vs EventMap) |
|---|---|---|
| **Snap Map** (Snapchat) | Живая карта, хотспоты с публичными Snaps/видео с мест (~400M MAU) | Не про события города: нет афиши, организаторов, билетов, категорий |
| **Bump** (преемник Zenly) | Реалтайм-геолокация друзей и мест | Про друзей, не про события |
| **Life360 / znaidy** | Семейная/дружеская геолокация | Безопасность/трекинг, не события |

Snap Map — **ближе всего по духу** (живая карта + видео с мест), но это «друзья и хотспоты», а не город событий.

### C. Видео-ленты — формат, но не карта

TikTok / Snapchat Spotlight — вертикальное видео и discovery, но без географической «живой карты сейчас происходящего».

## 2. Свободный угол EventMap

EventMap стоит на пересечении, которое сейчас не занято целиком:

```
                 Живая карта (real-time)
                          │
        Snap Map ●        │        ● EventMap  ← здесь свободно
     (друзья+видео)       │     (события сейчас + видео +
                          │      локальный контент + билеты)
   ───────────────────────┼───────────────────────  События / афиша
                          │
                          │        ● Ticketon / Sxodim / Eventbrite
                          │          (афиша + билеты, без «живого»)
                       Каталог (static)
```

- **Snap Map** = живое + видео, но без событий.
- **Ticketon / Eventbrite** = события + билеты, но без живого слоя.
- **EventMap** = соединяет оба слоя **для конкретного города** (Алматы/КЗ): что идёт *сейчас* и *скоро* на карте, live-видео с места, локальные организаторы, билеты, рейтинги.

Это не «ещё один Eventbrite» и не «Snap Map». Отличие честное и конкретное.

---

## 3. Риски (без розовых очков)

1. **Холодный старт контента — главный риск.** Пустая карта = мёртвый продукт. Выигрывают те, у кого есть поток событий. Это важнее, чем код.
2. **Большие игроки могли бы добавить события** (Snap Map технически близко), но им не до Алматы — локальность это твоя фора, а не вечная защита.
3. **Live-видео дорого** по инфраструктуре и модерации — правильно держать его слоем поверх MVP, а не ядром на старте.
4. **Дифференциация должна быть видна за 5 секунд** — иначе пользователь воспримет как «очередную афишу».

---

## 4. Стратегия холодного старта (как наполнить карту)

Цель первых месяцев — чтобы карта **никогда не была пустой** в целевом городе (Алматы).

**Шаг 1. Импорт афиши (день 1, без ожидания организаторов).**
Парсить/агрегировать публичные события из Ticketon, Sxodim, площадок и пабликов → карта сразу «живая» даже без единого зарегистрированного организатора. Помечать как «из афиши», апгрейдить до «живых» по мере прихода организаторов.

**Шаг 2. Сфокусироваться на одном городе и нескольких категориях.**
Не «вся страна», а Алматы + 3–4 категории, где плотность высокая (концерты, спорт, бары/акции, лекции/квизы). Плотность важнее охвата — на карте должно быть «густо».

**Шаг 3. Завести 10–20 «якорных» организаторов вручную.**
Точечно подключить активные площадки/промоутеров, дать им бесплатный продающий инструмент (карточка + билеты). Они приводят аудиторию и контент.

**Шаг 4. Сделать «сейчас» якорем продукта.**
Раздел «Прямо сейчас» (live-видео + идущие события) — причина открывать приложение каждый вечер, а не раз в месяц перед концертом. Это то, чего нет у афиш.

**Шаг 5. Локальный сетевой эффект.**
Sharing/«я тоже здесь», подписки на организаторов и людей → каждое событие тянет участников, участники тянут видео, видео тянет зрителей.

**Метрика успеха раннего этапа:** не скачивания, а **плотность живой карты вечером пятницы в Алматы** и доля пользователей, открывающих «Прямо сейчас» повторно.
