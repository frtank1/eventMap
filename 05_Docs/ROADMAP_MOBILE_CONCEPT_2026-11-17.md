# EventMap — мобильный концепт и задачи по важности (17.11.2026)

## Концепт, который уже собирается и открывается на телефоне

**«Живая карта Астаны: что происходит в городе сейчас».** Мобильная веб-версия (`02_Code/web`),
которую можно установить на главный экран (PWA). Магазины приложений не нужны.
Внутри тот же 3D-движок, что и в нативном приложении (`02_Code/game-city`).

Основной сценарий (весь он уже работает в сборке):
1. Открыл — видишь 3D-город с событиями-шариками. Фильтры: Все / Сегодня / Завтра / Выходные; день или ночь по времени Астаны.
2. Тап по событию — карточка: когда, где, описание, цена, «Открыть в 2ГИС», «Поделиться». Ссылку `?event=<id>` можно отправить другу.
3. Тап по зданию — адрес и события в радиусе 150 м.
4. «Мой образ» — собираешь себя: мужское или женское тело, голова (причёска или головной убор), верх, низ, обувь, рюкзак, рост, фигура, цвета кожи, волос и одежды. Аватар гуляет по площади.
5. Возле Байтерека ходят анимированные прохожие (декоративные, не реальные люди).

Как открыть на телефоне сейчас (без хостинга), когда Mac и телефон в одной Wi-Fi:
```sh
cd 02_Code/game-city && npm run build -- --preview-only
cd ../web && npm run build && npm run serve:phone   # печатает http://<IP Mac>:8790/
```
Чтобы установить: Safari → «Поделиться» → «На экран „Домой“» или Chrome → «Установить приложение».
Полноценная установка (standalone) работает только по HTTPS, то есть после хостинга (P0-1).

## P0 — чтобы концепт был у людей в руках к 30 ноября

| # | Задача | Кто решает | Готово, когда |
|---|---|---|---|
| 1 | Хостинг + домен: любой статический хостинг (Cloudflare Pages / Netlify / GitHub Pages), выложить `web/dist`. Самый большой файл — 15 MB (`city-geometry.emc`) | **владелец** выбирает хостинг и домен; деплой только по его просьбе | ссылка открывается на телефоне по HTTPS |
| 2 | Вес первой загрузки: сейчас около 57 MB на диске, по сети примерно 25–35 MB. Цель — не больше 10 MB до первой картинки: людей грузить при открытии «Мой образ» или при приближении, `city-geometry.emc` и `world/` проверить на необходимость при старте | агент | замер на 4G меньше 10 секунд до первой картинки |
| 3 | Проверка на реальных телефонах: iPhone (Safari) и средний Android — FPS, нагрев, память. Возле площади сейчас около 155 draw calls | владелец смотрит, агент чинит | 30+ FPS на среднем Android, без вылетов |
| 4 | Контент: 30–50 настоящих событий на декабрь (сейчас 11) и обложки категорий в `web/covers/` | агент собирает, владелец проверяет | при старте на карте видно 20+ событий |
| 5 | «Предложить событие»: выбрать канал (Google Form, Telegram-бот или WhatsApp) и записать в `config.json → suggestUrl` | **владелец** | кнопка видна и ведёт в рабочую форму |
| 6 | Стартовый вид: камера показывает события, а не только Байтерек; подсказка в одну строку («Нажми на шарик…») | агент | новый пользователь за 5 секунд понимает, что делать |
| 7 | Закоммитить текущую работу (людей, NSDI, web PWA) | **владелец** разрешает | коммит в рабочей ветке |

## P1 — первые 2–3 недели после запуска

- Этажность зданий из NSDI: запустить импорт на Mac (`node import-nsdi-city.mjs astana && node apply-nsdi-heights.mjs && node build.mjs`), приложить письмо-разрешение в `05_Docs/licenses/NSDI.md`.
- Люди: слить материалы каждой части в один (вершинные цвета), чтобы draw calls упали в 3–4 раза; подписать варианты головы («Короткая», «Каска», «Ирокез» вместо названия наряда).
- Service worker: повторный заход без перекачки 10+ MB, работа при слабой сети.
- Аналитика без персональных данных: сколько открыли, сколько нажали на событие, сколько поделились.
- Визуальные баги, на которые жаловался владелец: проверять по одному зданию за раз (стадион, Talan, Хазрет Султан, парки).

## P2 — глубина продукта (требования владельца из HANDOFF §0)

- События с бэкенда (Ktor, Render): `apiEvents`, заявки и модерация. Статус Render не проверен.
- Кабинет площадки (MEGA, Астана Арена): утверждать заявки на свои события, редактировать своё здание.
- MEGA «раскрывается» на 3 этажа и показывает, что происходит внутри.
- Анимированные объекты события: сцена, поле, ярмарка.
- «Где мои близкие»: только по взаимному согласию, с аккаунтами и отключаемой геопозицией; продумать приватность до кода.

## P3 — нативные приложения и масштаб

- Android: закончить миграцию AGP9 (`02_Code/MIGRATION_AGP9.md`). WebView с тем же движком уже подключён (`GameCityView.android.kt`). Внутреннее тестирование в Play Console.
- iOS: WKWebView (`GameCityView.ios.kt`), TestFlight.
- Push-уведомления о событиях рядом.
- Алматы и Шымкент: импорт NSDI уже есть, движку нужна поддержка нескольких городов.
- Решение по 2ГИС как базовой карте (не принято).
