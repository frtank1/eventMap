# Бэклог: фичи, требующие сперва Figma + документацию

Процесс: **идея → макет в Figma → описание здесь → реализация в коде.**
Сюда попадают фичи, которые НЕ реализуем вперёд дизайна. Подключение уже нарисованных
экранов к логике в этот список не входит (это просто реализация существующего дизайна).

## Создание события (D6–D8)

- **Пикер точки на карте (шаг 2 «Где это будет»).** Сейчас в `CreateEventScreen` нарисована
  карта-заглушка (сетка + 📍), точку выбрать нельзя. Координаты временно подставляются центром
  Астаны + разброс (см. `CreateEventViewModel`, TODO). Нужен макет: как выбирать точку
  (перетаскивание карты под пин / поиск адреса), как показывать выбранное.
- **Date/Time-пикер.** Сейчас дата и время — свободный текст («5 июля», «08:30»), уходит на бэк
  как есть (невалидный ISO, но хранится строкой). Нужен макет календаря/времени и формат.
- **Загрузка обложки.** Кнопка «🖼️ Добавить обложку» — пока no-op. Бэкенд-плумбинг загрузки
  готов (`/media/presign` + `/media/confirm`, переиспользуется из video). Нужен макет: выбор
  из галереи/камеры, кроп, превью.

## Карта

- **Открыть событие на карте из карточки.** В `EventDetailScreen` нет кнопки «показать на карте».
  Нужен макет: где кнопка, как анимируется переход (камера летит к координатам — `controller.animateCamera`
  уже есть). До макета — не реализуем.
