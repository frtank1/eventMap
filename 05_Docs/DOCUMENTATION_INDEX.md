разные статусы. Пилоты не заменяют концепцию и не означают готовность релиза.

нового продукта:

- `USER_STORIES.md`;

Если старый документ противоречит `EVENTMAP_NEW_CONCEPT.md`, действует новая
концепция, с учётом более поздних требований владельца, перечисленных в передаче
аналитику. Предложения из передачи требуют согласования и не объявляют новые
функции реализованными.
