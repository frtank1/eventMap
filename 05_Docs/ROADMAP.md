## Критический путь

```
API-контракт ─► Backend auth ─► клиент auth ─► карта на данных ─► событие
Mapbox-спайк ─────────────────────────────────► карта на данных
Решение по видео ──────────────────────────────────────────────► LIVE/видео-спринт
```
Если Mapbox-спайк (M0) выявит проблемы с overlay — переключаемся на план Б (MapLibre), бюджет +1 неделя.

## Риски

| Риск | Влияние | Митигация |
|---|---|---|
| Overlay поверх карты тормозит | высокое | спайк в M0; план Б MapLibre |
| Видео/LIVE сложнее оценки | высокое | проектирование в M0, буфер в Спринте 3 |
| Mapbox-биллинг превысит бюджет | среднее | оценить лимиты в M0, MapLibre как fallback |
| Соло-загрузка / отпуска | среднее | сроки целевые, ревью в конце спринта |
| Приватность гео + Sharing | среднее (юр.) | privacy policy + возрастной гейт к M6 |
