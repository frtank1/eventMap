# EventMap Event V2 — единая модель городской активности

## Принцип

Event — всё, что происходит или должно произойти в городе: концерт, матч,
свадьба, набор команды на футбол, временная торговля, наблюдение в телескоп
или замеченный очевидцами запуск дронов.

Отдельные продукты и таблицы для каждого сценария не создаются. Различия
описываются полями Event, правами автора и сигналами участников.

## Базовая сущность

| Поле | Значения | Назначение |
|---|---|---|
| `kind` | `planned`, `gathering`, `live_signal`, `private` | Характер события |
| `sourceType` | `organizer`, `business`, `government`, `initiator`, `witness` | Кто публикует |
| `visibility` | `public`, `unlisted`, `invite` | Кто видит |
| `joinPolicy` | `open`, `approval`, `invite` | Как присоединяются |
| `audience` | `everyone`, `family`, `adults` | Аудитория |
| `capacity` | число/null | Лимит участников |
| `minAge` | число/null | Минимальный возраст |
| `expiresAtMs` | timestamp/null | Автоисчезновение живого сигнала |
| `proofMediaId` | media id/null | Непубличное подтверждение брони/чека |
| `confirmationCount` | число | Независимые «Я тоже это вижу» |
| `interestCount` | число | «Мне интересно» |

Существующие поля названия, описания, координат, времени, категории, цены,
обложки и организатора сохраняются.

## Три слоя карточки

1. **От автора** — официальное описание, условия и медиа.
2. **С места** — подтверждения, фото и ролики людей с гео/QR-присутствием.
3. **Интерес города** — сколько заинтересованы, идут и подтверждают.

Организатор не может собственными публикациями увеличить
`confirmationCount`: подтверждение принадлежит независимому пользователю.

## Живые сигналы

Несколько сигналов объединяются в один Pulse, если совпадают:

- расстояние (начальный радиус 150 м);
- окно времени (30 минут);
- категория;
- нормализованный заголовок.

Уровни доверия:

- 1 — замечено;
- 2 — подтверждается;
- 3–4 — происходит сейчас;
- 5+ — городской импульс.

Действия различаются:

- `confirm` — «Я тоже это вижу»;
- `interest` — «Мне интересно»;
- `join` — «Я присоединяюсь».

## Права авторов

- Любой подтверждённый пользователь создаёт `gathering`, `live_signal` и
  приватное событие.
- Аккредитованный бизнес получает `sourceType=business` и коммерческую метку.
- Государственный/официальный аккаунт получает отметку только после ручной
  модерации.
- Официальная карточка выборов, экстренного сообщения или государственного
  мероприятия требует первоисточник и не редактируется обычными пользователями.

## Безопасность

- Частный пользователь не может публиковать таргетинг «только детям».
- Семейные активности отображаются как `audience=family` и рекомендуют
  сопровождение взрослого.
- Точный адрес приватного Event скрывается до приглашения/одобрения.
- Документ брони или чек не публикуется; пользователю показывается только
  статус проверки.
- Жалобы, блокировка автора и автоистечение применяются ко всем типам Event.

## Туманный город

Официальная информация о публичных запланированных событиях видна всем.
Участнические медиа и спонтанные сигналы могут быть скрыты до приближения к
геозоне. Район открывается личным присутствием, а не публикацией организатора.
