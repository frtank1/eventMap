# EventMap — Backlog фич

Все фичи продукта, сгруппированные по эпикам. Каждая фича имеет приоритет (P0 — must have для MVP, P1 — важно для релиза 1.0, P2 — после релиза).

---

## EPIC 1. Карта и события

- **F1.1 [P0]** Отображение карты с текущей локацией пользователя.
- **F1.2 [P0]** Пины событий на карте с иконкой по категории.
- **F1.3 [P0]** Кластеризация пинов при отдалении.
- **F1.4 [P0]** Bottom-sheet с деталями события при тапе на пин.
- **F1.5 [P0]** Автоматическое исчезновение пина организатора, если он не проводит активных событий (TTL).
- **F1.6 [P1]** Тепловая карта активности (где сейчас много людей).
- **F1.7 [P1]** Маршрут до события.
- **F1.8 [P2]** Оффлайн-карта избранных регионов.

## EPIC 2. Создание и управление событиями

- **F2.1 [P0]** Создание события: название, описание, локация, время, категория.
- **F2.2 [P0]** Загрузка обложки события.
- **F2.3 [P0]** Редактирование и удаление своих событий.
- **F2.4 [P0]** Указание организатора (профиль организации).
- **F2.5 [P1]** Повторяющиеся события (каждую субботу).
- **F2.6 [P1]** Лимит участников и регистрация.
- **F2.7 [P2]** Платные билеты.

## EPIC 3. Категории и жанры

- **F3.1 [P0]** Базовые категории: концерты, спорт, еда, скидки, для детей, забеги, образование.
- **F3.2 [P0]** Подкатегории и теги (например «марафон», «5к», «детский»).
- **F3.3 [P0]** Фильтр на карте по категориям и жанрам.
- **F3.4 [P1]** «Мои интересы» — какие категории показывать по умолчанию.

## EPIC 4. Авторизация и профили

- **F4.1 [P0]** Регистрация по email + пароль.
- **F4.2 [P0]** Логин через Google.
- **F4.3 [P1]** Логин через Apple (нужно для App Store).
- **F4.4 [P0]** Профиль пользователя: имя, аватар, био.
- **F4.5 [P1]** Профиль организатора: логотип, описание, контакты, рейтинг.
- **F4.6 [P1]** Верификация организатора (галочка).

## EPIC 5. Подписки и уведомления

- **F5.1 [P0]** Подписка на организатора.
- **F5.2 [P0]** Подписка на жанр/категорию.
- **F5.3 [P0]** Лента «Мои подписки» — события из подписок.
- **F5.4 [P1]** Push-уведомления о новом событии у подписанного организатора.
- **F5.5 [P1]** Напоминания за час до события, на которое подписан.
- **F5.6 [P2]** Email-дайджест раз в неделю.

## EPIC 6. Живые отзывы (видео-моменты)

- **F6.1 [P0]** Запись короткого видео (до 30 сек) с привязкой к локации или событию.
- **F6.2 [P0]** Просмотр видео-отзывов внутри карточки события.
- **F6.3 [P0]** Лента «Прямо сейчас» — последние видео в радиусе N км.
- **F6.4 [P1]** Лайки и комментарии к отзывам.
- **F6.5 [P1]** Модерация (репорт + автоматический фильтр).
- **F6.6 [P2]** Live-трансляции.

## EPIC 7. Социальное — «человек как событие» и подписка на людей

- **F7.1 [P1]** Карта людей: пины пользователей, которые показали свою активность.
- **F7.2 [P1]** «Сейчас здесь» — статус активности пользователя.
- **F7.3 [P0]** Подписка на пользователя (с approve, если профиль закрытый).
- **F7.4 [P0]** История посещений (моя — всегда; чужая — по разрешению).
- **F7.5 [P0]** Гранулярные настройки приватности: что видно подписчикам (текущая локация / вся история / только места с медиа / рекомендации / видео-отзывы / фото).
- **F7.6 [P0]** Рекомендации пользователя — публичный список его любимых мест и событий (если разрешено).
- **F7.7 [P1]** Друзья и взаимные подписки → автоматический бо́льший доступ.
- **F7.8 [P1]** Блокировка пользователя (черный список).
- **F7.9 [P1]** Запросы на подписку (для приватных профилей).
- **F7.10 [P2]** Режим «инкогнито» при просмотре чужой истории.

## EPIC 11. Живая галерея события (UGC к событию)

- **F11.1 [P0]** Загрузка фото к событию участниками (любой, кто отметился «иду»/«был»).
- **F11.2 [P0]** Загрузка видео к событию (до 60 сек) участниками.
- **F11.3 [P0]** Просмотр галереи события (фото и видео вместе, свайп).
- **F11.4 [P0]** Лайки и комментарии под медиа.
- **F11.5 [P0]** Атрибуция: подпись автора под каждым медиа, переход в его профиль.
- **F11.6 [P1]** Организатор может скрыть / удалить неподходящее медиа из своей галереи.
- **F11.7 [P1]** Жалоба на медиа.
- **F11.8 [P2]** Сортировка галереи (новые / популярные / от друзей).
- **F11.9 [P2]** Папки галереи по дням многодневных событий.

## EPIC 8. Поиск

- **F8.1 [P0]** Поиск событий по названию.
- **F8.2 [P0]** Поиск организаторов и людей.
- **F8.3 [P1]** Поиск по тегам.
- **F8.4 [P2]** История поиска и рекомендации.

## EPIC 9. Платформа и инфраструктура

- **F9.1 [P0]** Compose Multiplatform проект (Android + iOS).
- **F9.2 [P0]** Backend API (Ktor) с PostgreSQL + PostGIS.
- **F9.3 [P0]** Object storage для изображений и видео (S3-compatible).
- **F9.4 [P0]** Аналитика (Firebase / Amplitude).
- **F9.5 [P0]** Crash reporting (Sentry / Crashlytics).
- **F9.6 [P1]** CI/CD: GitHub Actions для сборки Android и iOS.
- **F9.7 [P1]** Desktop версия Compose for Desktop.
- **F9.8 [P2]** Web-версия (Compose for Web).

## EPIC 10. Модерация и безопасность

- **F10.1 [P0]** Жалобы на события и пользователей.

- **F12.2 [P0]** Фирменный пин на карте: логотип, цвет подсветки, постоянное присутствие.

- **F12.4 [P1]** Статистика бизнеса: просмотры пина, переходы, участники.

- **F15.3 [P0]** CTA-логика: «Приду»/«Купить»/«Я тоже здесь» (гео ≤300 м) (D1c). ✅ бэкенд 11.06
