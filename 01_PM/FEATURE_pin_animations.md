# Фича: анимации пинов на карте (бесплатные + платные)

Дата: 2026-06-13. Статус: спека на согласование. Источник идеи: azamat.

## Суть
У каждого пина на карте (событие / бизнес-место) может проигрываться анимация.
Пользователь выбирает её из списка. Два источника анимаций (СВОИ НЕ ЗАГРУЖАЮТСЯ):

1. **Встроенные (бесплатные)** — простые эффекты: Пульс, Волна, Свечение, Мигание.
   Рисуются кодом, красятся в цвет пина. Доступны всем сразу. Это НЕ файлы — это код.
2. **Премиум (платные)** — каталог анимаций, которые можно **купить** (тематические под
   матч: Кайрат, Тобол; праздничные; брендовые). После покупки доступны для своих пинов.
   Это файлы Lottie, которые добавляет владелец проекта (админ), пользователи только покупают.

## Где выбирают (2 точки входа)
- **Создание события** — организатор выбирает анимацию для пина события (матч Кайрат-Тобол).
- **Экран бизнес-пина** — бизнес выбирает анимацию для своего пина (UI-заготовка уже есть).

В обоих местах список = бесплатные эффекты + купленные премиум. Некупленные премиум видны
с ценой и кнопкой «купить».

## Где показывается
На карте, на пине события/места. При отдалении упрощать (перформанс).

## Формат и контент-пайплайн (ответ на «в каком формате и как я добавляю»)
- **Формат: Lottie (`.json`)** — векторный, лёгкий (КБ), масштабируемый, кроссплатформенный.
  Бэкенд уже под него (`lottieKey`). НЕ используем GIF/видео (тяжёлые, мыльные).
- **Где брать:** готовые на LottieFiles.com (есть бесплатные и платные); кастомные
  (Кайрат/Тобол, брендовые) — рисует дизайнер в After Effects + плагин Bodymovin → экспорт `.json`.
- **Как ты добавляешь (админ):** залить `.json` в хранилище (Cloudflare R2 / S3) → получить
  ключ/URL → создать запись в каталоге (категория, название, цена, ключ). Через эндпоинт
  `POST /admin/animation-sets` (уже есть) или для MVP — сидом через SQL-миграцию. Позже —
  простой экран-админка для загрузки/цены.
- **Бесплатные эффекты** добавлять не нужно — они в коде.

## Что уже есть в бэкенде (переиспользуем)
- `pin_animations` (category, name, lottieKey) + `PinAnimationRepository` (byCategory/byId/add).
- У бизнес-аккаунта `animationId` + `PATCH /business/pin`; `GET /business/animations`.
- `POST /admin/animation-sets` — админ грузит анимацию в набор категории (Lottie-ключ, R2).
- Платёжная инфраструктура (заказы/билеты, провайдер mock) — основа для покупки анимаций.

## Чего НЕ хватает (нужно добавить)
**Бэкенд:**
- Поле `price` / `isPremium` у анимации.
- Таблица «купленные анимации» (userId/businessId → animationId) + проверка владения.
- Эндпоинты: каталог (`GET /animations?category=`), покупка (`POST /animations/{id}/purchase`,
  по образцу билетов), мои купленные (`GET /animations/my`).
- Поле `animationId` у события (сейчас только у бизнеса).

**Клиент:**
- Рендер анимаций на пине карты: эффекты — кодом; премиум-Lottie — через Compottie.
- Экран-каталог: бесплатные / премиум (с ценой) / купленные; покупка.
- Подключить выбор в создании события и на бизнес-пине (заготовка → реальные данные).

НЕ делаем: загрузку анимаций пользователями/бизнесом (только админ-каталог + покупка).

## Технически про рендер
- **Встроенные эффекты** — чистый Compose (пульс/волна/свечение), без библиотек, параметр = цвет.
- **Премиум** — Lottie через **Compottie** (`io.github.alexzhirkevich:compottie`), грузит по URL.

## Поэтапный план
- **Этап 1 (фундамент):** встроенные эффекты + рендер на пинах карты + подключить выбор
  на бизнес-пине и в создании события (пишет animationId). Без новых либ, без денег.
- **Этап 2 (Lottie):** Compottie + премиум-каталог из бэка по категориям (Кайрат/Тобол),
  рендер Lottie на пине.
- **Этап 3 (монетизация):** price/premium у анимаций, покупка (по образцу билетов),
  «мои анимации», гейтинг премиум до покупки.
