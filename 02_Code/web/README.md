# EventMap — веб-версия карты

Публичная страница с живой 3D-картой Астаны и событиями города. Это оболочка вокруг
движка из `../game-city`: движок используется как есть, без правок, через тот же мост,
что и в мобильном приложении. Аккаунтов, оплаты и записи на сервер здесь нет.

Создано 16.11.2026 под запуск к 30 ноября (см. `05_Docs/HANDOFF_FABLE_5.2_2026-11-16.md`).

## Что умеет

- Показывает события из `events.json` на карте: шарики движка, карточка события
  (когда, где, описание, цена), «Поделиться», «Открыть в 2ГИС», ссылка на источник.
- Фильтры «Все / Сегодня / Завтра / Выходные» по времени Астаны (UTC+5), а не по
  часам посетителя. Прошедшие события исчезают сами.
- Ссылка на событие: `?event=<id>` открывает его карточку.
- День и ночь — по времени Астаны, с ручным переключателем. Зимняя тема — с 1 декабря,
  новогодняя — с 20 декабря по 10 января (`"theme"` в `config.json` это отменяет).
- Нажатие на здание показывает адрес и события рядом (до 150 м).
- Кнопка «Предложить событие» появляется, если в `config.json` задан `suggestUrl`.

## Команды

```sh
cd ../game-city && npm run build -- --preview-only   # собрать движок
cd ../web
npm test            # проверки логики (без браузера)
npm run build       # собрать ./dist
npm run serve       # http://127.0.0.1:8790/  (демо-данные: ?demo=1)
```

`dist/` — обычные статические файлы: их можно выложить на любой статический хостинг.
Сборка падает, если в `events.json` есть некорректная или повторяющаяся запись:
событие не должно молча пропасть с карты.

## На телефоне

`npm run serve:phone` (то же, что `HOST=0.0.0.0 node serve.mjs`) печатает адрес вида
`http://192.168.x.x:8790/`: его можно открыть на телефоне в той же Wi-Fi. Сборка кладёт в `dist/` файл
`manifest.webmanifest` и иконки из `icons/`, поэтому после выкладки по HTTPS страницу можно установить
на главный экран (PWA). В CSP движка для этого добавлено только `manifest-src 'self'`.
Задачи по важности: `05_Docs/ROADMAP_MOBILE_CONCEPT_2026-11-17.md`.

## События: `events.json`

Массив объектов. Обязательные поля отмечены звёздочкой.

| Поле | Значение |
|---|---|
| `id`* | латиница, цифры, `-`, `_`; уникальный |
| `title`* | до 120 символов |
| `lat`*, `lng`* | числа, в пределах Астаны |
| `startAt`* | ISO-время со смещением, например `2026-12-05T19:00:00+05:00` |
| `endAt` | то же; без него событие считается идущим 3 часа |
| `category` | `sport`, `music`, `market`, `discovery`, `route`, `quest`, `community`, `newyear`, `kids`, `art`, `theatre`, `education` |
| `place`, `address`, `description`, `price` | текст |
| `url`, `source` | ссылка на первоисточник и его название |
| `cover` | `covers/<имя>.jpg`, если у события своя обложка |

Обложки категорий: файл `covers/<категория>.jpg` (или `.webp`, `.png`) подхватывается
сборкой автоматически. Без обложки показывается значок категории из движка.

`config.json`: `suggestUrl` — куда ведёт «Предложить событие»; `apiEvents` — адрес,
отдающий события в этом же формате (если задан и отвечает, заменяет `events.json`);
`siteUrl` — адрес сайта для превью ссылок; `demoEvents: false` убирает демо-режим.

## Что не сделано и не проверено

- В `events.json` 11 настоящих событий (30 ноября – 24 января), собранных 17.11.2026 с
  текущей афиши sxodim.com/astana; три из них сверены со страницей события. Цены и время
  могут измениться — перепроверить перед выкладкой. Для запуска нужно 30–50.
  `events.sample.json` — вымышленные данные только для `?demo=1`, с красной пометкой.
- Проверено в настольном Chromium без видеокарты: вёрстка, карточка, фильтры.
  На телефоне, в Safari и на реальном хостинге не запускалось. Скорость 3D не измерялась.
- При узком экране и близкой камере движок скрывает шарики, которые не помещаются
  целиком. Начальный вид страницы стоит сделать шире — это правка движка.
- Сервер событий не подключён: формат ответа бэкенда отличается от `events.json`,
  нужен адаптер либо отдельный эндпоинт. Нет аналитики, нет своей иконки сайта.
- Обложки категорий ещё не добавлены в `covers/`: 6 из 12 сгенерированы, ссылки — в
  `05_Docs/STATE_FOR_NEXT_AGENT_2026-11-17.md`.
