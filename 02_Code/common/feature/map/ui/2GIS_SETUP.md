# 2GIS: подключение карты EventMap

Дата проверки документации: 2026-10-30.

## Статус и границы

Добавлен Android-адаптер нативного 2GIS Map SDK 14.2.0. Он реализует существующие
`EventMap` и `EventMapController`: камера, проекция точек, день/ночь. Главная карта
и выбор координат события используют этот интерфейс. События, кластеры и остальные
Compose-слои продолжают получать данные от EventMap API.

Пока у владельца проекта нет ключа, провайдер по умолчанию остаётся `mapbox`.
Для 2GIS используется параметр сборки `eventmap.mapProvider=2gis`. Оба SDK в одну
сборку не включаются. Это переходный механизм до проверки 2GIS на устройстве.

iOS, Desktop и Wasm пока имеют прежние заглушки. Этот параметр включает только
Android-реализацию; он не означает готовность остальных платформ.

Проверено 2026-10-30: компиляция модуля карты для обоих провайдеров и полная
сборка `:androidApp:assembleDebug` с 2GIS прошли успешно. Проверки на устройстве
и загрузки картографических данных не выполнены: ключа пока нет. Универсальный
debug APK с нативными библиотеками для четырёх архитектур занимает около 236 MiB;
перед распространением нужно отдельно проверить размер release/AAB.

## Доступ и ключ

1. Открыть [Менеджер Платформы 2GIS](https://platform.2gis.ru/).
2. Оформить доступ к API, необходимым для мобильного SDK Map. Для базовой карты
   нужен доступ к картографическим данным; поиск мест/подсказки оплачиваются и
   настраиваются отдельно, если понадобятся.
3. Скачать файл `dgissdk.key`. Текущая инструкция 2GIS указывает, что бесплатные
   demo-ключи не работают в мобильном SDK. Точный тариф нужно проверить в кабинете.
4. Если привязываешь ключ к App ID, для Android приложения это `com.eventmap`.
5. Положить файл в `02_Code/androidApp/src/main/assets/dgissdk.key`.
   Каталог `assets` при необходимости создать. Сам ключ исключён из Git.

Ключ MapGL JS не является заменой файла ключа нативного SDK. Не вставлять
содержимое ключа в переписку, документацию или репозиторий. CI должен добавлять
этот файл из своего защищённого хранилища перед сборкой.

## Сборка

Из каталога `02_Code`:

```sh
./gradlew :androidApp:assembleDebug -Peventmap.mapProvider=2gis
```

Для проверки Kotlin-кода адаптера:

```sh
./gradlew :common:feature:map:ui:compileAndroidMain -Peventmap.mapProvider=2gis
```

Для постоянного выбора в локальной среде можно добавить в пользовательский
`~/.gradle/gradle.properties`:

```properties
eventmap.mapProvider=2gis
```

После изменения параметра выполнить Gradle Sync. Для сборки прежнего провайдера
использовать `-Peventmap.mapProvider=mapbox`. Неверное значение останавливает сборку.

Отсутствующий/пустой ключ обрабатывается до инициализации SDK: экран показывает
«Карта временно недоступна» и кнопку повторения. SDK создаётся один раз на процесс,
а экземпляры карты освобождаются при уходе с экрана. Дополнительный сбор персональных
данных SDK не разрешается автоматически. Ключ нельзя заменить в работающем процессе:
после добавления ключа приложение нужно пересобрать и перезапустить.

## Проверка на устройстве после получения ключа

- Карта Астаны загружается; видны улицы и здания, атрибуция 2GIS не перекрыта.
- При панорамировании, увеличении, вращении и изменении размера экрана маркеры
  остаются на своих координатах. Проекция возвращает физические пиксели.
- Смена день/ночь сохраняет положение камеры и события.
- Нажатие на кластер перемещает камеру, на событие — открывает его карточку.
- В форме события центральная метка выбирает те же координаты, что видны на карте.
- Уход/возврат, сворачивание приложения, поворот устройства и одновременное
  существование главной карты и выбора места не вызывают падений.
- Нет интернета, неподходящий/просроченный ключ и отказ сервера проверяются отдельно.
  Успешная компиляция не подтверждает загрузку тайлов или доступность подписки.

## Следующие этапы миграции

1. Получить ключ и пройти проверку Android на устройстве.
2. Подключить 2GIS iOS SDK через Swift Package Manager и адаптер Swift/UIKit →
   Compose; сейчас iOS-карты в проекте нет. Проверить ключ и bundle ID для iOS.
3. Отдельно поставить поиск адресов/организаций и выбор входа в здание. Они не
   появляются автоматически от замены базовой карты.
4. При необходимости веб-карты использовать MapGL JS с отдельной настройкой
   доступа. Desktop остаётся отдельным решением.
5. После приёмки сделать 2GIS провайдером по умолчанию и удалить переходный Mapbox.
