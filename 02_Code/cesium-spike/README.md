# Cesium · тест у Байтерека (spike, 17.11.2026)

Проверка CesiumJS 1.147 (Apache-2.0) на наших данных — без Cesium ion и без токенов.
Это тест, а не часть приложения или веб-сборки.

- Здания: контуры и этажность НИПД (`game-city/data/nsdi/astana.json`), радиус 2,4 км, высота = этажи × 3,3 м.
- Ориентиры: наши модели из `game-city/content`, сконвертированные в glTF (`build-data.mjs`).
- События: `web/events.json`.
- Подложки — только для теста: Esri World Imagery и тайлы OSM. Перед релизом нужен лицензированный источник.

Запуск:

```sh
cd 02_Code/cesium-spike
tar -xzf vendor/cesium-1.147.0-build.tgz -C vendor   # если vendor/Cesium нет
node build-data.mjs                                    # data/ (нужен импорт НИПД)
mkdir -p ../web/dist/cesium-spike && rsync -a --exclude '*.tgz' ./ ../web/dist/cesium-spike/
cd ../web && npm run serve        # http://127.0.0.1:8790/cesium-spike/
```

`npm run build` в `web/` удаляет `dist/` — после сборки нужно скопировать заново.

Замеры на Mac (браузер приложения Claude, окно 375×812):

- Cesium 2,7 МБ в gzip, всего 3,3 МБ без тайлов подложки.
- Город (8 896 зданий и 11 моделей) строится за 0,5–4 с.
- 100 FPS с тенями.

На телефоне ещё не мерили.

## Визуальный проход 1 (17.11)

- Окна и межэтажные полосы рисуются шейдером по реальной этажности. Вдали сетка гаснет, чтобы не рябило.
- Цветные крыши у малоэтажек: терракота, бирюза, сланец, шалфей. У высоток — серые.
- Ночь включается сама по реальному солнцу (`czm_sunDirectionWC`): горит часть окон, спутник темнеет, ориентиры подсвечены, работает bloom.
- Кнопка «Качество»: Эконом — пиксели CSS; Хорошо — до 2× пикселей; Макс — плюс ambient occlusion.

Чего нет: деревьев, людей, машин, разных типов фасадов, снега и дождя. Всё это уже есть в нашем three.js-городе.

## Демо-сцена мероприятия (17.11)

Кнопка «★ 3D-сцена» или нажатие на фиолетовый пин «3D». Это **вымышленный концерт** для показа возможностей, а не настоящее событие.

- Сцена собирается из конфига `scenes/demo-concert.json` (код `event-scene.js` — прототип EventSceneRuntime): на каждое мероприятие свой конфиг или шаблон, а не новый код.
- Состав: сцена с анимированными LED-экранами, лазеры, «волны» света по фан-зоне, VIP, фуд-корт и торговые палатки с гирляндами, входы и выход, парковка с машинами и автобусами, анимированные маршруты гостей. Толпа — 3 140 точек, часть мерцает «фонариками».
- Цена на Mac: после компиляции шейдеров 6–9 мс на кадр со сценой и без неё. Первый показ сцены — около 0,2 с на компиляцию.
