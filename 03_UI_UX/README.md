## Ключевые решения дизайна (ревизия 11.06.2026)

- Карточка события = фуллскрин-рилс (TikTok-style), описание — в шторке снизу (D1a/D1b)
- Лента рилсов: открытый ивент → похожие → сегодня (утро→вечер) → завтра…; при активном фильтре C8 — по фильтру
- CTA: «Приду» (free, до старта) / «Купить» (платное; покупка = «иду», билеты друзьям ±аккаунт) / «Я тоже здесь» (после старта, только при гео-совпадении ≤300 м)
- 18+ тумблер при создании события → бейдж + скрытие у несовершеннолетних
- Раздел M: бизнес-аккаунт юрлица — апгрейд из обычного, БИН + модерация, пин с анимацией из набора своей категории (наборы грузит админ)
- Раздел Q: промо-квесты от бизнеса — конструктор (точки + условия гео/фото/QR-покупка + награда), прохождение с QR-призом
- Рилс-иконки: ❤️ / 💬 D9 комментарии / ↗ D10 шэр / 🔔 D11 напоминание
- Живая карта 2.0: механики G1–G16 (MAP_CONCEPT §10) — пульс города, поток людей, туман войны, маяки, компас, спонтанный пульс, Wrapped, сезонный пасс и др. MVP-тройка: G1+G2+G9
