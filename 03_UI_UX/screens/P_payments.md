# P. Платежи и оценки (Figma: страница «💳 P»)

## P1 Оплата билета
Карточка события, счётчик билетов (−/N/+), блок «Кому ещё покупаешь»: друг с аккаунтом (увидит билет, попадёт в «идут») / «Без аккаунта» (учтён в счётчике анонимно, в списке не виден) / «＋ Добавить». Способы: Kaspi/карта/Pay. Итого. Пояснение про анонимный «+N». «Оплатить» → P2/P3.

## P2 Успех
✓, «Билеты у тебя!», карточка-билет с QR, строка «Ты и @друг — в списке „идут“ · +1 анонимно», «К событию →» (→P4 после), «Поделиться билетом».

## P3 Ошибка
✕, причина, деньги не списаны, «Повторить» (→P1), «Сменить способ».

## P4 Оценка ивента
«Как прошёл …?», 5 звёзд, быстрые теги (атмосфера/смешно/артисты топ/дорогой бар/мало мест), отзыв-поле, видимость для организатора и рейтинга места, «Отправить» / «Позже».
