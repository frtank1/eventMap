# F. Подписки и уведомления (Figma: страница «🔔 F·G»)

## F1 Мои подписки
Табы «Организаторы/Жанры/Люди», список с пилюлей «✓ Подписан».

## F2 Лента подписок
Карточки событий от подписок: организатор, LIVE-бейдж, тайтл, мета. → D1a.

## F3 Запросы на подписку
Для приватных профилей: список с «Принять»/«✕».

## F4 Уведомления
Список: иконка, текст, время; непрочитанные подсвечены точкой. Типы: LIVE рядом, напоминание, лайки, ответы, билеты.

## F5 Настройки уведомлений
Тумблеры per-канал: LIVE рядом (радиус), подписки, напоминания (🔔), социальное, билеты, email-дайджест.
