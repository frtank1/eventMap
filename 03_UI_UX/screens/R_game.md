# R. Геймификация (Figma: страницы «🌃 C2.0» и «👤 H»)

## R1 Игровой хаб
Карточка уровня: номер, титул («Городской исследователь»), XP-бар до следующего. Значки-ачивки (от квестов, районов, жанров; 🔒 закрытые). Сезонный пасс (G13): название сезона, прогресс «3/7 квестов», трек лута — реальные призы от бизнес-аккаунтов (кофе/проходки/мерч). Миссии (G14): совместная с другом (2×XP), туман войны («открой район»), новый жанр. Лидерборд районов недели (G10). Входы: пилюля уровня в H1.

## R2 «Твой год в городе» (G12, Wrapped)
Сторис-экран в декабре: «Ты прожил город на N событий», мини-карта следов, топ-место, топ-жанр, км пешком, новые друзья, % исследования. «↗ Поделиться в сторис».

## R3 Капсула времени (G15)
Лонг-тап по месту на карте → шторка: фото + послание, получатель («другу» — откроется только на этом месте / «себе через год» / «всем, кто придёт»), «💊 Закопать капсулу». Пин-капсула 💊 на карте для получателя.
