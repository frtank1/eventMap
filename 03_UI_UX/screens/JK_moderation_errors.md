# J. Модерация · K. Ошибки (Figma: страница «⚙️ I·J·K»)

## J1 Пожаловаться
Контекст жалобы, радио-список причин (спам, опасный контент, 18+ без метки, фейк, оскорбления, авторские права, другое), «Отправить».

## J2 Мои жалобы
Карточки со статусами: на проверке (жёлтый) / принята (зелёный) / отклонена (серый).

## J3 Ограничение аккаунта
⛔, срок и причина, что осталось доступным, «Оспорить решение».

## K1–K4 Пустые состояния
Шаблон: эмодзи, заголовок, текст, primary + ghost. K1 нет сети (офлайн-кэш) · K2 нет событий («Расширить радиус» / «Создать событие») · K3 нет подписок («Выбрать интересы») · K4 ошибка сервера («Повторить»).
