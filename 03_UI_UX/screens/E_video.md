# E. Видео (Figma: страница «📹 E»)

## E1 «Прямо сейчас»
Вертикальная лента live-рилсов: заголовок с пульс-точкой, LIVE-пилюля, реакции, «📍 карта», автор+«Следить», локация-пилюля, нижняя навигация с FAB 🎬 (→E3).

## E2 Плеер из события
TikTok-плеер с контекст-пилюлей «Из события · …», реакции, подпись с хэштегами, «открыть событие ›».

## E3 Запись (30 сек)
Таймер-пилюля «● 0:11/0:30», прогресс-полоса, инструменты (камера/вспышка/таймер/эффекты), шаттер, галерея, звук. → E4.

## E4 Превью + публикация
«↺ Переснять», стикеры (😍/🔥/Aa/🎵), шторка: подпись, эмодзи, «📍 Привязать к событию», «Опубликовать».

## E5 Архив моих видео
Статистика (видео/просмотры/❤️), сетка 9:16 с просмотрами и LIVE-метками.
