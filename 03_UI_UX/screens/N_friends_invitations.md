# N. Друзья и приглашения (Figma: страница «💌 N»)

Правила: друзья = взаимная заявка. Приватное событие (`visibility=private`) не видно на общей карте/в поиске/в ленте рилсов — пин, рилс и галерею видят только приглашённые. Гости без приложения получают ссылку/QR → веб-открытка с RSVP (канал роста). API: §8.7.

## N1 Мои друзья
Счётчик, поиск, блок «Заявки в друзья» (аватар, общие друзья/события, Принять/✕), список друзей со статусами присутствия: «🟢 сейчас на …», «рядом · N км», «был онлайн…». У каждого — 💌 (позвать). CTA «💌 Создать приглашение» → N2.

## N2 Приглашение — тип и шаблон
Чипы типа праздника (свадьба, день рождения, той/кудалык, выпускной, новоселье, вечеринка). Карусель анимированных шаблонов открытки (превью с именами). Поля: название, место, дата/время. Тумблер «🔒 Приватное — только по приглашению» (вкл по умолчанию). → N3.

## N3 Гости и рассылка
Чек-лист друзей, группы-чипы (семья/универ/работа), счётчик выбранных. Пунктирная карточка «🔗 Без приложения? Ссылка/QR». Пояснение приватности. «💌 Разослать N приглашений» → отправка пушей и открыток.

## N4 Пригласительное (у гостя)
Анимированная открытка по шаблону: эмодзи праздника, имена, «приглашают тебя…», дата/время (акцент), место с переходом на карту, дресс-код/столик, счётчик «N гостей · M уже придут». Кнопки «✓ Приду» / «Не смогу 😔», «📅 Добавить в календарь». Ответ виден только организатору. Веб-версия по link_token — то же без аккаунта (имя вручную).

## N5 RSVP-дашборд (организатор)
Статы: позвано/придут/не смогут/молчат. Список гостей с пилюлями статуса (включая «+1» и гостей по ссылке). «🔔 Напомнить молчунам». В день события гео-чекин гостей = «Я тоже здесь» → видно, кто на месте. Галерея события общая, видна только гостям. «✏️ Редактировать приглашение».
