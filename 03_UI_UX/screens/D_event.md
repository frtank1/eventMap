# D. Событие — рилс-формат (Figma: страница «🎬 D»)

## D1a Карточка события = рилс (шторка свёрнута)
Фуллскрин-видео 9:16. Верх: назад, пилюли LIVE·N/категория/18+, ⋯; пилюля порядка ленты «↕ Похожие → сегодня → завтра» (по фильтру C8, если активен). Справа: ❤️ лайк, 💬 (→D9), ↗ (→D10), 🔔 (→D11). Низ: организатор+✓, тайтл, мета. Шторка: grab-handle, подсказка «потяни вверх», чипы (место·расст/время/цена), CTA, гео-статус. Свайп ↕ = следующее событие. Тяга шторки вверх → D1b (Smart Animate).

## D1b Шторка раскрыта
Затемнение видео, шторка ~80%: тайтл, мета, инфо-строки (место/время/цена/организатор), описание, сегменты «Галерея · N» / «Участники · N», CTA-бар («Я тоже здесь» + 🔔). Свайп вниз → D1a.

## D1c Состояния CTA (логика)
1) До начала, free → «🙋 Приду» (список «идут», напоминание).
2) До начала, платное → только «🎟️ Купить · цена»; покупка = авто-«иду»; билеты друзьям: с аккаунтом — видны в списке, без — анонимный «+N» в счётчике.
3) Идёт + гео ≤300 м → «📍 Я тоже здесь» активна, «✓ локация совпадает».
4) Идёт + далеко → кнопка disabled, «активируется рядом с местом». «Приду» сама превращается в «Я тоже здесь» в момент старта.

## D2 Галерея события
Сетка медиа от участников, LIVE-метки, «＋ Добавить своё» (→D5). Тап → D4.

## D3 Участники
Сегменты «Идут·N / Были·N», список (аватар, имя, статус, пилюля «тут/иду/был»), друзья сверху, анонимные покупки видны только числом.

## D4 Просмотр медиа = рилс
Фуллскрин 9:16, свайп ↕ по галерее, счётчик «3/86», автор, подпись, реакции, пилюля «открыть событие ›».

## D5 Добавить медиа
Зона загрузки (фото/видео ≤30 с), подпись, эмодзи, привязка к событию, «Опубликовать».

## D6–D8 Создание события (3 шага)
D6: обложка, название, описание. D7: точка на карте, адрес, ориентир. D8: дата/время, категория-чипы, цена, лимит, тумблер «🔞 Только 18+» (скрытие у несовершеннолетних + бейдж). «✓ Опубликовать».

## D9 Комментарии (шторка)
Заголовок «Комментарии · N», список (аватар, ник, время, текст, «Ответить», ♡ с числом, вложенные ответы), инпут-бар с аватаром и ➤.

## D10 Поделиться (шторка)
Ряд друзей EventMap, ряд приложений (Telegram/WhatsApp/Instagram/ссылка/ещё), «Отмена».

## D11 Колокольчик-напоминание
Состояния выкл/вкл (за 1 час и в старт), тост «✓ Напомним за час…». Не равен «приду»; для платных включается автоматически после покупки. Настройки каналов — F5.
