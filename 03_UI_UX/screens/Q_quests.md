# Q. Промо-квесты (Figma: страница «🎮 Q», MAP_CONCEPT §11)

## Q1 Каталог «Игры рядом»
Карточки квестов с бренд-градиентом: эмодзи, тайтл, автор (✓ бизнес), мета (точки, тип проверки, срок, N прошли), награда-пилюля 🎁. На карте C1 квесты — точки 🎮 с пунктирным маршрутом.

## Q2 Карточка квеста
Мини-карта точек: ✓ пройдена / активная (свечение) / 🔒 по цепочке; пунктирный маршрут. Прогресс-бар «2/4» + 🎁. Список условий по точкам со статусами. Награда и счётчик финишёров. «➜ К точке N · расстояние» → Q3.

## Q3 Чек-ин точки
Заголовок точки, «✓ ты на месте». Тип проверки задаёт создатель: 📍 гео-чекин (механика «Я тоже здесь», ≤300 м) / 📷 фото на месте (гео-метка обяз., попадает в галерею квеста) / 🧾 покупка — скан QR на чеке. Последняя точка → Q4.

## Q4 Финиш
🎉 «Квест пройден!», номер финишёра, карточка приза с QR (срок действия), значок-ачивка в профиль, «↗ Поделиться победой».

## Q5 Конструктор (бизнес)
Название; точки на мини-карте (1–10); условие (гео/фото/QR-покупка); тумблер «по цепочке»; награда (текст + кол-во призов, выдача QR-купоном); срок; «Опубликовать · цена». Модерация как у событий бизнеса.

## Q6 Статистика (бизнес)
Начали/прошли/конверсия/новые клиенты; воронка по точкам (бар-чарт); галерея фото участников; «Продлить квест».
