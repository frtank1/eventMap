# H. Профиль (Figma: страница «👤 H»)

## H1 Мой профиль
Аватар, ник, гео; пилюля уровня «7 · Городской исследователь · XP» со значками (→R1); статы (подписки/подписчики/события/видео); «Редактировать» (→H3), ⚙ (→I1); табы События/Галерея/Рекомендации/История/Видео; сетка контента.

## H2 Чужой профиль
То же + «✓ Подписан»/«Подписаться», 💬; табы по разрешениям приватности; «История скрыта настройками» если закрыта.

## H3 Редактирование
Фото, имя, о себе, город, «Сохранить».

## H4 / H5 История посещений
H4 моя: карточки с гео-подтверждением «📍 был». H5 чужая: только разрешённое + «🔒 ещё N скрыто».

## H6 Рекомендации
Карточки «место + цитата-совет».

## H7 Приватность профиля
Тумблеры: профиль всем, история, видео, рекомендации, Sharing, показывать в «идут».

## H8 Профиль организатора
Хиро, ✓, рейтинг «★ 4.8 · N оценок», статы, «Подписаться», табы События/Галерея/Отзывы.

## H9 Редактирование организатора
Название, описание, жанры, контакты.

## H10 Верификация
Чек-лист (документы, фото событий, соцсети), «Отправить заявку». Для юрлиц → раздел M.

## H11 Sharing «Сейчас я здесь»
Карточка с тумблером, авто-выключение через 3 ч; настройки: кто видит, точность, скрытие на 18+.
