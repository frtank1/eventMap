## Порядок работы (рекомендация)

1. **Завершаем «горячий» путь карты:** C5 → C6 → C3 → C4 → C7 → C8
2. **Событие и галерея:** D1 → D2 → D3 → D4 → D5
3. **Видео-флоу:** E1 → E3 → E4 → E2
4. **Создание события:** D6 → D7 → D8
5. **Профили:** H1 → H8 → H2 → H7 → H6 → H4
6. **Подписки и поиск:** F1 → F2 → G1 → G2
7. **Онбординг и auth:** A1 → A2 → A3 → A4 → A5 → A6 → A8 → B1 → B2 → B3
8. **Чистка:** I*, J*, K* — служебные, делаем в конце

## Связи между экранами (главные переходы)

```
C1 (карта) ─── тап пин ───┬─► C4 (sheet скоро)  ─► D1 (карточка события)
                          ├─► C5 (sheet LIVE)   ─► C6 (плеер видео)
                          └─► C7 (sheet человек) ─► H2 (чужой профиль)

D1 ─► D2 (галерея) ─► D4 (медиа фуллскрин)
D1 ─► D5 (добавить медиа) → камера E3 → превью E4

H1 (мой профиль) ─► H3 (редактирование)
                ─► H4 (история)
                ─► H7 (приватность)
                ─► H11 (Sharing)

+ кнопка (центр нав) ─► E3 (запись видео) ─► E4 (превью) ─► публикация
```
