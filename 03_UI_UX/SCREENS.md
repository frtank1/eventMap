## D. Событие (8)

> Карточка события = фуллскрин-рилс (TikTok-style). Свайп ↕ листает события, порядок ленты после тапа по ивенту на карте: 1) открытый ивент → 2) похожие на него (совпадения: категория, жанр, близость) → 3) все за сегодня (утро→вечер) → 4) все за завтра (утро→вечер) и т.д. Если задан фильтр карты (C8) — лента строится по фильтру. Описание — в шторке снизу. CTA: «Приду» до старта (бесплатные) / только «Купить» (платные, покупка = «иду») → «Я тоже здесь» после старта (активна только при совпадении геолокации, ≤ 300 м).

## M. Бизнес-аккаунт / юрлицо (6) — новые

Апгрейд из обычного аккаунта (вход из профиля/настроек). Верификация: БИН/ИИН + модерация документов (1–2 дня). Анимации пина на карте загружаются админом заранее наборами по категориям; бизнес видит и выбирает только анимации своей категории.

| Код | Экран | Статус |
|---|---|---|
| M1 | Промо «Бизнес-аккаунт» (преимущества, вход в флоу) | ✅ |
| M2 | Шаг 1 — данные компании (БИН/ИИН + автоподстановка, бренд, контакты) | ✅ |
| M3 | Шаг 2 — категория бизнеса (определяет набор анимаций) | ✅ |
| M4 | Шаг 3 — отображение на карте (логотип, цвет, анимация из набора категории, живое превью) | ✅ |

## N. Друзья и приглашения (5) — новые

Друзья = взаимная заявка. Приватные события (свадьба, день рождения, той): не видны на общей карте — пин/рилс/галерею видят только приглашённые. Гости без приложения — по ссылке/QR в браузере. RSVP виден организатору; в день события гео-чекин показывает, кто на месте.

| N1 | Мои друзья (заявки, статусы «на событии»/«рядом», поиск) | ✅ Figma |

| N3 | Выбор гостей (друзья, группы, ссылка/QR для не-юзеров) и рассылка | ✅ Figma |
| N4 | Пригласительное у гостя (открытка, «✓ Приду / Не смогу», календарь) | ✅ Figma |

## P. Платежи и оценки (4) — новые, см. ADR-002

> Платное событие: кнопки «Приду» нет — только «Купить». Успешная покупка автоматически добавляет в список «идут». При покупке нескольких билетов можно указать аккаунты друзей (попадут в список) или не указывать — тогда система учитывает их в счётчике участников, но не показывает в списке (аноним «+N»).

| Код | Экран | Статус |
|---|---|---|
| P1 | Оплата билета (кол-во билетов, кому ещё: аккаунт/анонимно, сумма, Kaspi/карта/Pay) | ✅ Figma |
| P2 | Успешная оплата (билет + QR, кто в списке/аноним) | ✅ Figma |
| P3 | Ошибка оплаты / повтор | ✅ Figma |
| P4 | Оценить ивент (★ + быстрые теги + отзыв) | ✅ Figma |

> Плюс правки существующих: D1 (бейдж цены + «Купить» + блок рейтинга ★), C-пины (масштаб по importance), H8 (рейтинг организатора).
