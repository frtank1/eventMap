РЕШЕНИЕ МОДЕРАТОРА

От здания до места события

  1. Выберите здание.

    Связь с картой строится по постоянному ID, а не по совпадению адреса.

  2. Добавьте этажи и помещения.

    Схема необязательна. Если она есть, помещения можно выбирать на рисунке.

  3. Сохраните и проверьте.

    Черновик не виден пользователям. Предпросмотр показывает его отдельно от опубликованной версии.

  4. Опубликуйте.

    Приложение получит план при повторном открытии здания или нажатии «Обновить план и события». Обновление APK не требуется, если установленная версия поддерживает планы.

Доступ пока осуществляется общим административным ключом. Персональные роли и журнал действий сотрудников ещё не реализованы.
